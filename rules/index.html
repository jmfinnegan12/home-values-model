Rules

Markets: sixteen Kalshi events, one per city, each ending -30NOV26 · contract terms

  • Yes if the Zillow Home Value Index for single-family homes in the city, identified by Zillow region ID, is above the strike for November 2026.
  • Strikes: five per city, each its own market. "Above" means strictly greater than.
  • The figure: ZHVI, single-family homes, middle tier, smoothed and seasonally adjusted, in whole dollars, as shown on Zillow's Home Values page for the region with single-family selected. Zillow Research's data file is the fallback.
  • The first published value counts. Later revisions do not change the result.
  • Timing: trading closes 2026-12-17 at 10:00 a.m. ET, and can close early on release. Expected settlement 2026-12-19; latest 2027-01-04.
  • Not allowed to trade: Zillow staff and vendors with early access to the index, and anyone with material nonpublic information about it.
